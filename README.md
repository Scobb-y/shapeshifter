# shapeshifter
A mod I made for an event I did for friends, not intended for widespread use, but feel free to use it as you wish. 

## How it works
Shapeshifter is an assignable trait to any player on the server using "/ss {playername}"
- Shapeshifters can steal other players skins and voice recordings
### Abilities
- Passive: Takes extra damage and has permanent weakness while under direct sky during the day
- Active: Rage can temporarily remove passive debuff or if not afflicted then buff themselves gaining strength, speed, and regen 2
- Active: Hunt will highlight all players within 100 blocks for 30 seconds. If no players are found within 100 blocks then the coords will be given for the nearest player.
  
## Setup

- Requires https://www.curseforge.com/minecraft/mc-mods/simple-voice-chat as well!
- Runs on Fabric
- Stable Versions: 1.20.1
